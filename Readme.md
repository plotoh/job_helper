# 🤖 HeadHunter Auto-Responder (hhparser)

> Полноценная система автоматического парсинга и откликов на вакансии hh.ru с веб-управлением, интеллектуальным
> скорингом и поддержкой нескольких аккаунтов.

[![Python](https://img.shields.io/badge/Python-3.11+-blue.svg)](https://www.python.org/downloads/)
[![FastAPI](https://img.shields.io/badge/FastAPI-0.104+-green.svg)](https://fastapi.tiangolo.com/)
[![Playwright](https://img.shields.io/badge/Playwright-1.x-green.svg)](https://playwright.dev/python/)
[![Docker](https://img.shields.io/badge/Docker-24+-blue.svg)](https://www.docker.com/)

---

## 🚀 Ключевая идея

**Парсинг → Скоринг → Автоотклик** – всё в одном асинхронном процессе.  
Система самостоятельно ищет вакансии, оценивает их релевантность по вашему профилю и отправляет отклики в течение
рабочего дня, соблюдая паузы и лимиты. Управление – через веб-интерфейс и Telegram-бота (опционально).

## ✨ Возможности

| Функция                         | Описание                                                                                                        |
|:--------------------------------|:----------------------------------------------------------------------------------------------------------------|
| 🔍 **Парсинг вакансий**         | 5 окон в день (можно запустить вне расписания). Сбор деталей (зарплата, опыт, навыки, описание).                |
| 🎯 **Интеллектуальный скоринг** | Оценка от 0 до 100 на основе заголовка, уровня (Junior/Middle/Senior), опыта и свежести. Двойной учёт исключён. |
| 🧩 **Уровни вакансий**          | Разделение на Regular, Junior, Senior. Можно включать/отключать каждый уровень через веб-интерфейс.             |
| 👥 **Мультиаккаунтность**       | Поддержка неограниченного числа аккаунтов hh.ru. Каждый со своим файлом cookies и резюме.                       |
| ⏰ **Автоотклики**               | Отправка по расписанию с учётом дневного лимита, случайных пауз и рабочих часов.                                |
| 🌐 **Веб-интерфейс**            | Дашборд со статистикой, таблица аккаунтов, управление паузами, уровнями, откликами и принудительный парсинг.    |
| 📊 **Логи**                     | Подробные логи откликов: успехи, ошибки, тесты. Каждый тип в отдельном файле.                                   |
| 🧪 **Тесты работодателей**      | Автоматическое детектирование и логирование вакансий, требующих прохождения теста (без повторных попыток).      |
| 🛑 **Глобальное управление**    | Включение/выключение откликов, принудительный запуск парсинга вне окон.                                         |
| 📈 **Скоринг для всех**         | Пересчёт скора для новых и всех существующих вакансий (кнопка в интерфейсе).                                    |
| 📁 **Экспорт rejected**         | Выгрузка отклонённых вакансий в Excel через веб-интерфейс.                                                      |
| 🐳 **Docker**                   | Готовая контейнеризация для быстрого развёртывания (worker + PostgreSQL + web).                                 |

## 📦 Установка и запуск

### 1. Клонирование репозитория

```bash
git clone https://github.com/yourusername/hhparser.git
cd hhparser
```

### 2. Настройка переменных окружения

Скопируйте `.env.example` в `.env` (если есть) или создайте `.env` со следующими минимальными параметрами:

```env
# База данных
DB_HOST=postgres
DB_PORT=5432
DB_NAME=hhparser
DB_USER=user
DB_PASSWORD=pass

# Telegram (если нужен бот)
TELEGRAM_BOT_TOKEN=ваш_токен
TELEGRAM_ADMIN_ID=ваш_id
TELEGRAM_USERS_IDS=[123, 456]   # список разрешённых ID

# Аккаунт hh.ru
TG_USERNAME=@ваш_телеграм_ник   # используется в письмах
RESUME_ID=ваш_id_резюме
PARSING_COOKIES_FILE=cookies/parsing.txt
COOKIES_DIR=cookies

# Настройки работы
WORK_START_HOUR=9
WORK_START_MINUTE=13
WORK_END_HOUR=18
WORK_END_MINUTE=41
DAILY_LIMIT_MIN=53
DAILY_LIMIT_MAX=97
```

Полный список параметров – в файле `app/config.py`.

### 3. Запуск через Docker Compose

```bash
docker-compose up -d --build
```

Сервисы:

- **postgres** – база данных (порт 5432)
- **worker** – основной воркер (парсинг + отклики)
- **web** – веб-интерфейс (порт 8000)

### 4. Доступ к веб-интерфейсу

Откройте в браузере: [http://localhost:8000](http://localhost:8000)

## ⚙️ Конфигурация через веб-интерфейс

На главной странице дашборда вы можете:

- **Управлять откликами** – глобально включить/отключить.
- **Включать/отключать уровни Junior/Senior** – отклики будут идти только на выбранные уровни (Regular всегда активен).
- **Запускать парсинг вне окон** – немедленно запустить сбор вакансий.
- **Пересчитывать скор** – для новых вакансий (без скора) или для всех (force).
- **Ставить аккаунт на паузу/возобновлять** – с указанием длительности.
- **Смотреть последние логи откликов** и переходить к полному логу.

## 📁 Структура проекта (ключевые модули)

```
hhparser/
├── app/
│   ├── db/               # Модели, репозитории
│   ├── hh_client/        # Playwright-клиент для hh.ru (парсинг, отклик)
│   ├── scheduler/        # Воркеры, планировщик, аккаунт-воркеры
│   ├── scoring/          # Модуль скоринга вакансий
│   ├── utils/            # Утилиты, работа с настройками
│   ├── web/              # FastAPI-приложение, шаблоны, статика
│   ├── bot/              # Telegram-бот (опционально, отключён)
│   └── config.py         # Централизованная конфигурация
├── cookies/              # Файлы cookies для аккаунтов
├── logs/                 # Логи: отклики, тесты, rejected, worker.log
├── docker-compose.yaml
├── Dockerfile.worker
├── Dockerfile.web
└── requirements.txt
```
